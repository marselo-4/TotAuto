# Tot Auto — web del showroom

Web de Tot Auto (Tàrrega): showroom de deportivos y alta gama, stock, importación a medida y contacto. Castellano y catalán.

Next.js 16 · Tailwind 4 · next-intl · Supabase · GSAP + Lenis + Motion · React Three Fiber. Destino: Vercel con el dominio totauto.net.

## Arrancar

```bash
npm install
cp .env.example .env.local   # rellenar claves
npm run dev
```
